# armonia: Harmonize Multilingual and Longitudinal Research Data

Tools for harmonizing multilingual and multi-wave research datasets.
Generates an Excel-based data dictionary that maps raw variable names
and categorical values to a standardized schema, applies the mapping to
rename variables and recode factors to integers, safely row-binds and
column-binds waves, and anonymizes participant identifiers via salted
SHA-256 hashing.
